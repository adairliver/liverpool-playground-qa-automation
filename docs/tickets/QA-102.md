# QA-102 — Falla la prueba de login justo al escribir el usuario

**Tipo:** Bug · **Prioridad:** Alta · **Componente:** Suite de automatización · **Reporta:** Equipo de QA

## Descripción
La prueba de inicio de sesión se detiene en el primer paso en que debería capturar el usuario. La aplicación
funciona bien al probarla a mano: la pantalla de login carga y los campos aceptan texto.

## Comportamiento observado
- La prueba termina con un error inmediato en el paso de captura del usuario.
- El mensaje del error indica que el campo de usuario "no existe" en la prueba, aunque sí está visible en pantalla.

## Comportamiento esperado
La prueba captura usuario y contraseña, entra a la aplicación y llega al dashboard de pedidos.

## Cómo reproducir
1. Ejecutar la feature `02_login.feature`.
2. Observar el error en el paso "captura el usuario ... y la contraseña ...".

## Criterio de aceptación
- El escenario de login completa el flujo hasta ver el dashboard.
