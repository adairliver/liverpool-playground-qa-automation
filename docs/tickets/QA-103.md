# QA-103 — Error al seleccionar un pedido después de recargar la tabla

**Tipo:** Bug · **Prioridad:** Media · **Componente:** Suite de automatización · **Reporta:** Equipo de QA

## Descripción
En la pantalla de pedidos, la prueba recarga la página y luego intenta seleccionar el pedido 1002. En ese
momento la prueba falla con un error que dice que el elemento "ya no es válido / ya no está asociado a la página".

## Comportamiento observado
- La tabla se ve correcta en el navegador y la fila del pedido 1002 está presente.
- La prueba falla al hacer clic en esa fila, de forma consistente.

## Comportamiento esperado
Tras recargar, la prueba selecciona el pedido 1002 y la pantalla muestra "Pedido 1002 seleccionado".

## Cómo reproducir
1. Ejecutar la feature `03_seleccion_pedido.feature`.
2. Observar el error en el paso "recarga la página y selecciona el pedido".

## Criterio de aceptación
- El escenario selecciona la fila tras la recarga y verifica el detalle mostrado.
